# Security Policy

## Reporting

Please report security vulnerabilities privately to:

`info@peterdsp.dev`

Include the affected component, reproduction steps, impact and any suggested
mitigation. Do not include real passenger information or reusable credentials.

## Sensitive areas

Poravia treats these as especially sensitive:

- Booking-provider credentials and session material.
- Administrative review endpoints.
- Deployment and backup access.
- Source archives with restricted redistribution.
- Location, favorites and passenger information.

## Scope

The project is in its foundation phase. Supported release branches and a
coordinated disclosure window will be documented before the first public beta.
