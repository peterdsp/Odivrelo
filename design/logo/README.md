# Odivrelo brand assets

The "Route O" mark: a bold ring in deep teal blue, a road with lane dashes
sweeping up through it from the lower left, and a warm orange node on the upper
right of the ring where the road arrives. No artwork from the product's former
names survives here; it is in the git history only.

Everything in this directory, and every icon the apps ship, is generated by
`generate_odivrelo_brand.py` from one piece of geometry and the brand colours in
`../tokens/odivrelo.tokens.json`. Do not edit the outputs by hand.

## Regenerating

```sh
python3 -m venv /tmp/odivrelo-brand
/tmp/odivrelo-brand/bin/pip install -r design/logo/requirements.txt
/tmp/odivrelo-brand/bin/python design/logo/generate_odivrelo_brand.py
bash scripts/ios-generate-appicon.sh   # copy the iOS rasters into the asset catalog
```

The outputs are committed, so no build or CI job needs these dependencies. The
wordmark outline is cached in `src/wordmark.json` (Inter Bold, SIL Open Font
License 1.1); pass `--font /path/to/Inter-Bold.ttf` to refresh it.

## Masters

| File | Use |
|---|---|
| `odivrelo-symbol.svg` | Full colour symbol on a light ground, transparent background. |
| `odivrelo-symbol-on-dark.svg` | White ring and road, orange node, for dark grounds. |
| `odivrelo-symbol-black.svg`, `odivrelo-symbol-white.svg` | One-colour versions. |
| `odivrelo-symbol-mono.svg` | The whole mark as one `currentColor` silhouette with real holes. |
| `odivrelo-favicon.svg` | The simplified cut on a rounded deep teal blue tile, legible at 16 px. |
| `odivrelo-logo-horizontal*.svg` | Symbol plus outlined wordmark: full colour, on dark (`#0B4A6B` ground, white wordmark), black, white. |
| `odivrelo-app-icon.svg` | 1024 app icon master: white mark on deep teal blue, square, no corner mask. |
| `odivrelo-app-icon-light.svg` | Light ground variant. |
| `odivrelo-app-icon-dark.svg`, `odivrelo-app-icon-tinted.svg` | iOS dark and tinted appearances. |
| `png/` | Raster masters (1024 icon and symbol, 1600 px logos, 16/32/48 favicons, the brand board) and `png/ios/`, the iOS catalog rasters. |
| `../Odivrelo-Brand-Board.svg` | The brand board. |

## Where the assets are used

| Platform | Asset | Source |
|---|---|---|
| Web | `apps/web/public/favicon.svg`, `icons/icon-*.png`, `icons/apple-touch-icon.png`, `icons/maskable-*.png`, `icons/og-image.png`, `icons/mark-mono.svg` | this generator |
| Web | Header wordmark, welcome mark (`src/brand/Marks.tsx`) | `src/brand/markGeometry.generated.ts` |
| iOS | `AppIcon` (any, dark, tinted), `BrandMark` (settings, onboarding wordmark), `LaunchMark` (launch screen) | `png/ios/`, installed by `scripts/ios-generate-appicon.sh` |
| Android | Adaptive launcher icon (`ic_launcher_background`, `ic_launcher_foreground`, `ic_launcher_monochrome`), `ic_notification`, `ic_brand_mark` (About) | vector drawables written by this generator |

## Rules

- Keep clear space of a quarter of the ring's diameter on every side.
- Minimum sizes: 16 px (favicon, simplified cut), 60 px (mobile header), 1024 px
  (app icon master). Below 96 px use the simplified cut.
- Never recolour the orange node in a colour version. In a one-colour version
  it takes the same colour as the rest of the mark.
- Do not stretch, rotate, outline, add gradients or add a drop shadow.
- The app icon master is square with no baked-in corner radius. Every platform
  applies its own mask.
- Colours come from `../tokens/odivrelo.tokens.json`. Do not hardcode new ones.
