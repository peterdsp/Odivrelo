# Poravia brand assets

Original marks for Poravia. No HodoMap artwork survives here.

| File | Use |
|---|---|
| `poravia-mark.svg` | App icon and favicon source. Aegean teal ground, limestone arch, sun amber point. |
| `poravia-mark-mono.svg` | Single-colour mark using `currentColor`, for tinted icons, monochrome contexts and inline use. |
| `poravia-wordmark.svg` | Light-theme wordmark. |
| `poravia-wordmark-dark.svg` | Dark-theme wordmark. |

## What the mark means

An arch is a passage you travel through, which is what the invented name
Poravia was built to suggest. The amber point inside the opening is the exact
boarding point, the one fact the product exists to get right. At sixteen pixels
the arch and the point are still two distinct shapes, which is why the mark is
built from a thick stroke and a single filled circle rather than detail.

## Rules

- Keep clear space of at least the arch's stroke width on every side.
- Never recolour the amber point to teal; the contrast between the passage and
  the point is the whole idea.
- Never place the teal ground on a teal surface. Use the mono mark instead.
- Do not stretch, rotate, add gradients, or add a drop shadow to the mark.
- Colours come from `../tokens/poravia.tokens.json`. Do not hardcode new ones.
